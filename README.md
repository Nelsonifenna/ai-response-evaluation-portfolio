## Evaluation Method

I use a consistent evaluation framework:

| Criterion | Description |
|---|---|
| Accuracy | Factual correctness and reliability |
| Instruction-following | Compliance with the user's request |
| Relevance | How directly the answer addresses the task |
| Clarity | Readability and communication quality |
| Reasoning | Logical consistency and justification |
